# Emir Karatekin — Portfolio

Personal portfolio website built as a single, self-contained HTML file. Live at **[emirkaratekin.pl](https://emirkaratekin.pl)**.

## About

I'm a recent Computer Science graduate specializing in Mobile Application Design, focused on mobile and backend development. This site showcases my background, work experience, technical skills, and the EU-funded projects I've contributed to during my internship at MOBAD.

## Features

- Single-file build — one `index.html`, no build step, no dependencies to install
- Fully responsive, from mobile up to desktop
- Multi-language support (🇹🇷 Turkish · 🇬🇧 English · 🇵🇱 Polish) with an in-page language switcher; the selected language persists across visits
- Accessible by default — visible focus states and support for reduced-motion preferences
- Scroll-triggered section reveals

## Tech stack

- Plain HTML5, CSS3 (custom properties, CSS Grid/Flexbox), and vanilla JavaScript — no frameworks, no build tools
- [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk), [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans), and [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) via Google Fonts

## Running locally

No installation required — just open the file in a browser:

```bash
git clone https://github.com/emrkaratekin/emrkaratekin.github.io.git
cd emrkaratekin.github.io
open index.html   # or double-click the file
```

## Deployment

This repository is served directly by **GitHub Pages**, with a custom domain (`emirkaratekin.pl`) configured via DNS (A records pointing to GitHub's servers, HTTPS enforced). Any change pushed to the `main` branch is deployed automatically within a few minutes.
